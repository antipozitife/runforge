## Решения, которые я оставила в проекте

### React hooks вместо отдельного store

У страницы немного состояния, и оно не используется в других разделах.
Поэтому мне показалось достаточным оставить его в hooks.

### URLSearchParams вместо роутера

В приложении только одна страница. Для сохранения фильтров достаточно
<code>URLSearchParams</code> и History API, поэтому дополнительный роутер не нужен.

### Нативный dialog

Для панели деталей используется <code>&lt;dialog&gt;</code>. Он уже поддерживает
модальность, Escape и работу с фокусом.

### Отдельный сервис данных

Компоненты не импортируют mock напрямую. Данные загружаются через сервис,
возвращающий <code>Promise&lt;Run[]&gt;</code>. Благодаря этому позже можно
подключить настоящий API, не переписывая интерфейс.

### CSS-свечение

Световые лучи сделаны стилями, а не картинкой. Так они остаются чёткими на разных
размерах экрана и не требуют отдельного изображения.

## Ошибка, найденная во время работы

В первой версии кнопка закрытия деталей использовала <code>autoFocus</code>.
В React <code>StrictMode</code> фокус устанавливался раньше, чем сохранялся
элемент, открывший диалог. Поэтому после закрытия фокус возвращался неправильно.

Во время теста это стало заметно. Исправление получилось таким:

1. Убрали <code>autoFocus</code>.
2. Перед <code>showModal()</code> сохранили текущий <code>document.activeElement</code>.
3. Оставили нативному dialog выбор первой кнопки.
4. При закрытии вернули фокус на сохранённый элемент.

После этого отдельно проверили открытие через Enter, закрытие по Escape и возврат
фокуса на строку запуска.
